# Communication Rules

## Язык

- Все общение с пользователем вести на русском языке.
- Все GitHub issues, issue drafts, roadmap entries, worklog notes и user-facing тексты бота писать на русском языке, если пользователь явно не попросил другое.
- Комментарии в коде можно оставлять на английском только там, где это уже соответствует локальной конвенции файла.

## Стиль работы

- Писать коротко, по делу и без лишней бюрократии.
- Для продуктовых и UX-обсуждений учитывать не только код, но и удобство использования бота в реальном чате.
- Не терять договоренности из чата: если идея превращается в рабочую задачу, ее нужно зафиксировать в backlog.
