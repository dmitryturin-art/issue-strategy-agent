# Debugging Playbook

## Если бот отвечает не тем сценарием

Сначала проверить:
- `docs/WORKLOG.md` на недавние изменения поведения
- `app/bot.py` на порядок роутинга
- `app/trigger.py` на deterministic-эвристики
- `app/llm.py` на prompt и JSON-контракт намерений

## Если проблема в понимании формулировок

- Проверить, не перехватывает ли сообщение deterministic-ветка раньше LLM
- Проверить, как очищается и нормализуется текст
- Сравнить поведение для явной и неявной формулировки
- По возможности воспроизвести кейс на реальном сообщении в Telegram

## Если проблема в поиске issues

- Разделять два сценария:
  - список по статусу без темы
  - текстовый поиск по теме
- Для листинга по статусу проверять GitHub repo issues API
- Для текстового поиска проверять GitHub search API и очистку служебных слов

## Если менялась логика бота

1. Прогнать:
   `PYTHONPYCACHEPREFIX=/private/tmp/issue-bot-pycache venv/bin/python -m py_compile app/*.py`
2. Перезапустить локальный процесс бота
3. Проверить живой сценарий в Telegram
