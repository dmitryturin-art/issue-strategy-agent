## Практические замечания

- После изменений в логике бота желательно сначала прогнать синтаксическую проверку.
- Если бот уже запущен, нужно остановить текущий процесс и поднять новый из корня этого проекта, иначе будет работать старый код.
- Для операций с GitHub этого репозитория использовать обычную авторизацию git/GitHub, которая уже подключена в VS Code и работает для `git push`.
- Не путать этот доступ с `GITHUB_TOKEN` из `.env`: тот токен относится к самому боту и его рабочим GitHub-интеграциям, а не к сопровождению репозитория `issue-strategy-agent`.
