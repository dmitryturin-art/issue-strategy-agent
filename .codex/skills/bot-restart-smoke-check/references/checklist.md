# Restart Checklist

## Быстрый сценарий

1. Убедиться, что изменения сохранены в проекте.
2. Прогнать:
   `PYTHONPYCACHEPREFIX=/private/tmp/issue-bot-pycache venv/bin/python -m py_compile app/*.py`
3. Остановить текущий локальный процесс `python -m app.main`, если он уже запущен.
4. Поднять новый:
   `venv/bin/python -m app.main`
5. Проверить логи старта:
   - `Database initialized`
   - `Запуск бота`
   - `Start polling`
   - `Run polling for bot`
6. Проверить живой сценарий в Telegram, если менялось поведение.

## Когда быть осторожнее

- Если менялась маршрутизация сообщений, проверяй и явные, и неявные формулировки.
- Если менялась интеграция с GitHub, проверяй отдельно:
  - список issues
  - поиск issues
  - создание issue
- Если после рестарта бот молчит, сначала проверь, действительно ли поднят новый процесс из текущего корня проекта.
