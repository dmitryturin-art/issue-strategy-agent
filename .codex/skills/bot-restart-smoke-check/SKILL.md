# Bot Restart Smoke Check

Используй этот skill, когда в проекте менялась логика бота и нужно быстро и безопасно применить изменения локально.

## Что делать

1. При необходимости быстро прочитай:
   `docs/agent/runtime.md`, `docs/agent/workflow.md`, `docs/agent/debugging.md`
2. Перед рестартом прогоняй:
   `PYTHONPYCACHEPREFIX=/private/tmp/issue-bot-pycache venv/bin/python -m py_compile app/*.py`
3. Если бот уже запущен, останови текущий локальный процесс `python -m app.main`.
4. Запусти новый процесс из корня проекта:
   `venv/bin/python -m app.main`
5. Убедись по логам, что polling стартовал без ошибки.
6. Если задача касается поведения бота, предложи короткий smoke-check в Telegram на 1-3 реальных фразах.

## Важные правила

- Бот в этом проекте обычно запускается локально, не через `systemd`.
- Не считай рестарт успешным, пока не увидишь старт polling в логах.
- Если проблема связана с пониманием формулировок, после рестарта проверяй именно живой сценарий в Telegram, а не только локальные эвристики.
